# 자료 출처

실험의 입력과 실행 환경을 확인할 수 있는 공개 자료다. 저장소의 [비교 실험 범위](../project/experiment-scope.md)와 [평가 근거 안내](../project/evidence-guide.md)에는 이 프로젝트에서 사용한 조건과 결과 위치를 정리했다.

- [COCI 공식 사이트](https://hsin.hr/coci/): 사용한 2025/2026 문제와 공식 테스트 데이터. 내려받는 파일·해시·설치 방법은 [README](../../README.md#실제-테스트-데이터-준비)에 정리했다
- [llama.cpp](https://github.com/ggml-org/llama.cpp): 로컬 모델 실행 기반. 실제 사용한 빌드·설정은 [실행 환경](../operations/environment.md)을 따른다
- [Hugging Face 모델 카드 안내](https://huggingface.co/docs/hub/model-cards): 모델 정보 확인 방식. 각 후보의 원 모델·배포 모델·라이선스 출처는 [모델 후보 조사](../project/model-candidates.md)에 있다

각 자료의 이용 조건은 해당 제공자의 안내를 따른다. 모델 가중치, API 키, 가상환경과 재배포 허용을 확인하지 못한 외부 자료 사본은 배포에 포함하지 않는다.
