# 자료 출처와 공개 범위

## 교육 과정 자료

이 프로젝트는 교육 과정에서 제공된 「프로젝트 발제 문서」와 「프로젝트 수행 평가표」를 참고해 진행했다. 2026-09-16에 확인한 자료를 바탕으로, 저장소에는 [과제 맥락과 수행 범위](../project/assignment.md), [평가 근거 안내](../project/assignment-rubric.md)를 새로 정리했다.

교육 자료 원문의 공개 재배포 허용 여부는 확인되지 않았다. 따라서 현재 작업 트리에는 발제 HTML·Markdown 스냅샷, Notion 조회 원문, 원문을 옮긴 평가표를 포함하지 않는다. 접근 권한이 필요한 과정 내부 문서의 URL도 공개 출처 링크로 안내하지 않는다. 정리된 문서는 공식 발제·평가표를 대체하지 않는다.

2026-09-30 정리는 현재 파일을 대상으로 했다. **이전 Git 커밋에는 과거 사본이 남아 있으며, 이 변경은 Git 이력에서의 삭제를 뜻하지 않는다.**

## 공개 기술·데이터 출처

- [COCI 공식 사이트](https://hsin.hr/coci/): 사용한 2025/2026 문제와 공식 테스트 데이터. 내려받는 파일·해시·설치 방법은 [README](../../README.md#실제-테스트-데이터-준비)에 정리했다
- [llama.cpp](https://github.com/ggml-org/llama.cpp): 로컬 모델 실행 기반. 실제 사용한 빌드·설정은 [실행 환경](../operations/environment.md)을 따른다
- [Hugging Face 모델 카드 안내](https://huggingface.co/docs/hub/model-cards): 모델 정보 확인 방식. 각 후보의 원 모델·배포 모델·라이선스 출처는 [모델 후보 조사](../project/model-candidates.md)에 있다

공개 기술 문서와 각 자료의 이용 조건은 해당 제공자의 안내를 따른다. 교육 과정 원문, 모델 가중치, API 키, 가상환경은 이 저장소의 배포 자료에 포함하지 않는다.
