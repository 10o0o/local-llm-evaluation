# 실험 진행과 문서 안내

코딩 문제 풀이용 로컬 LLM을 비교한 실험은 2026-09-17에 종료됐다. 이 문서는 수행 흐름과 근거를 찾아보기 위한 안내다. 전체 규모는 [실험 범위](experiment-scope.md), 평가·선정 기준은 [요구사항](requirements.md)에 정리했다.

## 수행 흐름

1. 개인 알고리즘 학습에서 필요한 코드·설명의 조건과 모델 선정 순서를 정했다
2. 로컬 후보의 모델 카드, 라이선스, 양자화, 장비 요구를 조사하고 실제 실행 가능성을 확인했다
3. COCI 문제 10개의 입력과 평가 방법을 정리하고, 네 모델의 원본 응답·실패·설정을 기록했다
4. 저장된 코드를 공식 테스트 데이터로 채점했다. 시간 제한 재평가와 최소 수정 결과는 원본과 구분했다
5. 설명 평가와 응답 시간 등을 함께 검토하고 로컬 후보를 선정했다

질문 구성은 [평가 질문](evaluation-questions.md), 지표와 누락값의 해석은 [기록 안내](../operations/recording.md), 최종 판단은 [선정 보고서](model-selection-report.md)에서 확인할 수 있다.

## 현재 후보와 HyperCLOVA 제외 이력

본 실험의 로컬 후보는 Qwen3.6과 Gemma4다. 초기 Ollama 실행에서 llama.cpp로 전환했고, reasoning budget과 서버 실행 옵션을 조정하며 동작을 확인했다.

HyperCLOVA는 NAVER llama.cpp 실행 도구로 연결·진단한 뒤 당시 구성의 지시 수행 문제로 제외했다. 해당 진단은 세 번째 로컬 모델의 본 비교 완료로 세지 않는다. [후보 조사](model-candidates.md#제외-이력-hyperclova)와 날짜별 [결정 이력](../history/decision-log.md)에 당시 확인 범위를 보존했다.

## 실험 규모와 조건 차이

로컬 2개와 Cloud 2개에 같은 10문항을 각 두 번 요청해 총 80회를 시도했다. 이전 답변이나 채점 결과를 다음 요청에 넣지 않았으며, 정상 응답 78건과 Motif-3의 호출 실패 2건을 남겼다. 호출 실패·코드 미생성도 모델별 20회 분모에서 빼지 않았다.

Cloud 비교는 초기 계획보다 확대했다. 일부 로컬 결과를 본 뒤 결정한 확장이므로 사전에 모든 비교 조건을 고정했다고 표현하지 않는다. 네 모델의 문제 목록·반복 수는 같지만 제공자와 생성 설정은 다르다. [Cloud 확장 기준](requirements.md#cloud-비교-확장-기준)에 그 차이를 기록했다.

워밍업은 본 실험과 분리했고 무저장 방침이어서 파일 증빙이 없다. 지표 누락·실제 적용 설정의 확인 범위는 [실행 환경](../operations/environment.md)을 따른다. 과거 60회 계획과 중단 기록은 당시의 이력으로 읽는다.

## 평가와 결과 해석

기준 채점은 공식 1배 시간 제한을 사용한다. 프로젝트 정책의 제한 재평가, 원본과 분리한 최소 수정, 사람이 입력한 설명 점수를 별도로 남겼다. 평가 정책을 생성 도중 확정한 사실도 유지했다. 선정 순서와 12/20회 최소 품질선은 이 프로젝트의 사용 목적에 맞춰 적용했다.

[평가 실행 안내](../operations/evaluation.md)는 명령과 기록 형식, [평가 근거 안내](evidence-guide.md)는 확인할 문서, [Local–Cloud 비교](local-cloud-comparison.md)는 실측과 운영 조건을 설명한다.

## 실행과 재현

현재 명령은 저장소 루트의 `uv run llm-eval`이다. 설치와 GPU·API 키 없는 합성 예제는 [README](../../README.md), 실제 데이터 준비·생성·채점은 [재현 안내](../operations/reproduction-guide.md)를 따른다.

`generate`의 `--round 1/2`는 본 실험 회차다. 생략하면 실제 모델을 새로 호출하는 시연 모드로 동작하며 `results/demo/`에 저장한다. `demo offline`은 고정 합성 예제를 쓰는 별도 명령이다. 파일·명령별 책임은 [아키텍처](../architecture.md)에 정리했다.

이전 Ollama 실행과 명령의 변경 경과는 [정리 이력](../history/README.md)에 남아 있다.

## 실험에서 제외한 범위

세 번째 로컬 모델의 본 비교, Transformers 직접 실행, 동일 모델 양자화 비교, Sentence Transformers 임베딩 실습은 이번 수행에 포함하지 않았다. 수행하지 않은 비교를 현재 결과의 근거에 포함하지 않는다.
