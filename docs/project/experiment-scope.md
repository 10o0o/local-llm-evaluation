# 비교 실험 범위

코딩 문제 풀이에 쓸 로컬 LLM을 선택하기 위해, 생성 코드의 실행 결과와 설명 품질을 비교했다. 로컬 서버의 추론·서빙 설정과 외부 API 응답을 다루고, 같은 공개 문제에서 얻은 결과를 기록했다.

## 비교 대상과 입력

- 로컬: llama.cpp로 실행한 Qwen3.6과 Gemma4
- Cloud: Luna와 Motif-3
- 입력: COCI 공개 문제 10개와 공식 시간·메모리 제한
- 반복: 모델마다 같은 문제를 두 번씩 요청해 총 80회 시도. 이전 답변과 채점 결과는 다음 요청에 전달하지 않았다

정상 응답은 78건이며 호출 실패 2건도 모델별 20회 분모에 남겼다. 모델별 제공자·생성 설정이 다르므로 동일한 토큰 예산에서 모델 자체의 우열을 검증한 실험으로 표현하지 않는다.

## 평가 방법

최초 응답에서 추출한 Python 코드를 공식 테스트 데이터로 채점했다. 공식 1배 시간 제한 판정과 네 문항의 2배 시간 제한을 반영한 프로젝트 정책 판정을 구분했다. 최소 수정본의 통과는 원본 정답률에 더하지 않았으며 설명 품질을 따로 평가했다.

Cloud 비교 확대와 평가 기준 확정은 생성이 시작된 뒤 이루어졌다. 변경 시점과 선정 우선순위는 [요구사항](requirements.md), 입력·조건 차이는 [평가 질문](evaluation-questions.md)에 기록했다.

## 결과와 해석 범위

로컬 후보로 Qwen3.6을 선택했다. 공식 1배 제한 AC는 Qwen 12/20, Gemma 9/20이고, 프로젝트 정책 AC는 각각 14/20, 9/20이다. 이는 10문항과 기록된 실행 조건에서의 결과다. 공개 문제의 학습 데이터 포함 여부, 다른 장비·태스크로의 일반화, 모든 파라미터 조합의 성능을 입증하지 않는다.
