# 교육 과정 프로젝트와 수행 범위

교육 과정의 로컬 LLM 비교 과제를 바탕으로, 코딩 문제 풀이에 쓸 모델을 고르는 실험을 진행했다. 이 문서는 프로젝트를 이해하는 데 필요한 사실을 정리한 요약이다. 교육 자료의 본문·예시·평가표를 옮기지 않았으며, 출처와 공개 범위는 [자료 출처](../sources/README.md)에 정리했다.

## 과제에서 출발한 범위

사용 목적과 실행 환경에 맞는 로컬 후보를 조사하고, 공통 입력으로 품질과 성능을 비교한 뒤 하나를 선정하는 과제였다. 기본 실험 규모는 서로 다른 로컬 모델 2개에 질문 10개를 두 번씩 적용하는 40회였다. Cloud 비교의 기본 범위는 모델 1개에 공통 질문 5개를 한 번씩 적용하는 것이었다.

실행 코드와 환경 정보뿐 아니라 응답 원본, 측정값, 비교 결과, 선정 이유를 함께 남기는 방향으로 진행했다. 사용 목적에 맞춘 정답 판정과 선정 우선순위는 [이 프로젝트의 요구사항](requirements.md)으로 구체화했다.

## 이번에 구현하고 실험한 범위

- 개인 알고리즘 학습을 사용 사례로 정하고, COCI 공개 문제 10개에서 Python 코드와 풀이 설명을 평가했다
- 로컬 Qwen3.6·Gemma4를 llama.cpp로 실행했다. Ollama에서 llama.cpp로 바꾼 경과는 [진행 안내](learning-guide.md#현재-후보와-hyperclova-제외-이력)에 남겼다
- Cloud는 Luna·Motif-3 각각 10문항×2회로 확장했다. 로컬과 합쳐 80회를 시도했고, 정상 응답 78건과 호출 실패 2건을 보존했다
- 공식 시간 제한의 코드 판정, 프로젝트 정책에 따른 제한 재평가, 원본과 분리한 최소 수정 평가, 설명 평가를 구분했다
- 최종 로컬 후보로 Qwen3.6을 선택했다. 작은 공개 문제 세트와 모델별 생성 설정 차이를 결과의 한계로 기록했다

Cloud 비교 확대와 평가 기준 확정은 생성이 시작된 뒤 이루어졌다. 이를 사전등록한 동일 조건 실험으로 표현하지 않는다. 세부 변경 시점과 기준은 [요구사항](requirements.md#평가-범위와-기준-확정-시점)을 따른다.

## 수행하지 않은 선택 범위

세 번째 로컬 모델의 본 비교, Transformers 직접 실행, 동일 모델의 양자화 비교, Sentence Transformers 임베딩 실습은 진행하지 않았다. 이 항목들을 실험 성과나 필수 미완료 항목으로 집계하지 않는다. HyperCLOVA의 초기 연결·진단은 세 번째 모델 본 비교와 구분한다.
